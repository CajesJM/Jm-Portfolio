# JM - Selected Projects

## TMC Connect

- Type: Mobile and web application
- Year: 2025
- Role: Lead developer and full-stack developer; mobile development, UI/UX, and API design
- Technologies: React Native, TypeScript, Firebase, and Expo
- Live project: https://cajes-jm-tmc-connect.vercel.app/
- Target users: Trinidad Municipal College students and event administrators

TMC Connect is a cross-platform campus event and attendance system for Trinidad Municipal College. It replaces paper attendance with QR check-ins, GPS verification, event management, and live analytics. Radius-based attendance permits check-in only when a student is within an event's designated location.

The system includes role-based access for Super Admin, Admin, and Student users, secure Firebase authentication, event registration, real-time attendance analytics, and offline persistence for unreliable campus Wi-Fi. Its goal is faster attendance with fewer lines and stronger protection against proxy attendance.

## Wipe It Good Trading Online Ordering Platform

- Type: Full-stack web application and client work
- Year: 2026
- Role: Sole developer and full-stack developer; commerce UX and API design
- Technologies: React, Vite, TypeScript, Node.js, Express, PostgreSQL, and Prisma
- Live project: https://wipeitgoodtrading.vercel.app/
- Target users: Customers and administrators of Wipe It Good Trading

This online ordering platform lets customers browse products, place orders, and track purchases while administrators manage products, orders, inventory, and customer records.

The system includes REST APIs, role-based access, a shopping cart, order tracking and status history, authentication, email verification, password recovery, customer and administrator notifications, Philippine address selection, map and geocoding support, and payment-ready checkout workflows.

The project addresses delays caused by manual seller conversations and gives customers a clearer path from product discovery to fulfillment.

## OJT Logbook Attendance

- Type: Responsive web application
- Year: 2026
- Role: Full-stack developer; product UI, UI/UX, and offline data architecture
- Technologies: React, TypeScript, IndexedDB, PDF, and DOCX
